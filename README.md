## NEAR Transaction Health Checker

A simple IronClaw skill that checks a NEAR transaction and explains its status in easy language.

## What it does

- Checks transaction status
- Shows gas used
- Shows sender and receiver
- Detects failed transactions
- Explains the result simply

## Example

Input:

text
Check this NEAR transaction:
YOUR_TRANSACTION_HASH


Output:
Status: Successful
Gas Used: 2.5 Tgas
Sender: example.near
Receiver: example.near

The transaction was successfully completed.
